## 🐛 Troubleshooting

### Invoice not appearing in Finance Portal?
```bash
# Check if invoice exists in database
psql -h localhost -p 5433 -U postgres -d crm_db
SELECT id, invoice_number, status FROM invoices ORDER BY id DESC LIMIT 5;
```
✅ Status should be: **PENDING**

### Customer still sees "Settle Invoice" button?
1. Hard refresh: **Ctrl+Shift+R**
2. Check browser console for errors (F12)
3. Clear localStorage: `localStorage.clear()` in console

### Backend not responding?
```bash
# Check backend process
curl http://localhost:8082/api/invoices
```

### PostgreSQL connection issues?
```powershell
# Restart PostgreSQL (admin PowerShell)
Restart-Service -Name "postgresql-x64-17" -Force
```
